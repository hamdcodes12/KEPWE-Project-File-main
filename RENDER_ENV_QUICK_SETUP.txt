STEP 1: Generate Required Secrets
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Generate BROKER_TOKEN_ENCRYPTION_KEY (32 bytes):
┌──────────────────────────────────────────────────────────────────────────┐
│ node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" │
└──────────────────────────────────────────────────────────────────────────┘
Copy the output ← Save this value

Generate JWT_SECRET (48 bytes):
┌──────────────────────────────────────────────────────────────────────────┐
│ node -e "console.log(require('crypto').randomBytes(48).toString('hex'))" │
└──────────────────────────────────────────────────────────────────────────┘
Copy the output ← Save this value


STEP 2: Add to Render Dashboard
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://dashboard.render.com
2. Select your "KEPWE" service
3. Click "Environment" (left sidebar)
4. Click "Add Environment Variable"
5. Add each variable below:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Variable Name:              BROKER_TOKEN_ENCRYPTION_KEY
Value:                      (Paste 32-byte hex from Step 1)
Status:                     ✓ REQUIRED

Variable Name:              JWT_SECRET
Value:                      (Paste 48-byte hex from Step 1)
Status:                     ✓ REQUIRED

Variable Name:              NODE_ENV
Value:                      production
Status:                     ✓ REQUIRED

Variable Name:              VITE_API_BASE_URL
Value:                      /api
Status:                     ✓ REQUIRED

Variable Name:              VITE_APP_NAME
Value:                      KEPWE - Everything Your Business Needs
Status:                     ✓ REQUIRED

Variable Name:              VITE_APP_ENV
Value:                      production
Status:                     ✓ REQUIRED


EMAIL SETUP (For OTP Authentication)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to https://resend.com → Sign up
2. Get your API key from Settings → API Keys
3. Add to Render:

Variable Name:              RESEND_API_KEY
Value:                      (Paste your Resend API key)
Status:                     ✓ REQUIRED (for OTP)

Variable Name:              OTP_FROM_EMAIL
Value:                      KEPWE <help@kepwe.in>
Status:                     Optional (uses default if not set)

STEP 3: Save & Deploy
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After adding all variables:
  1. Click "Save" button in Render
  2. Render will automatically redeploy
  3. Wait for deployment to complete (2-5 minutes)
  4. Check the deployment logs:

     Expected success message:
     ✓ [migrate] Migration completed successfully.
     ✓ [server] Listening on port 3000
     ✓ Build successful!

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Missing required production environment variables"
  → Check if BROKER_TOKEN_ENCRYPTION_KEY is set in Render Environment
  → Check if JWT_SECRET is set

❌ "Build failed"
  → Frontend build issue (check syntax)
  → Run locally: npm run build

❌ "Database connection failed"
  → Verify SUPABASE_DB_URL is set to the existing Supabase Postgres URL in Render
  → Check PostgreSQL is running

❌ "OTP not sending"
  → Verify RESEND_API_KEY is set
  → Verify domain is verified in Resend account
