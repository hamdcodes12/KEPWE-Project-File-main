# PROMPT 1 — IndexPilot Algo Dashboard & Authentication

We already have an existing **IndexPilot website/application**.

Do NOT create a separate website.

Add a new section called:

**IndexPilot Algo**

The goal of this phase is to build the complete **working client-side Algo Dashboard and authentication system**.

## 1. IMPORTANT

Before making changes:

* Inspect the existing project.
* Identify frontend framework.
* Identify backend.
* Identify database.
* Identify existing authentication.
* Identify routing structure.
* Reuse existing components and architecture wherever possible.
* Do NOT break any existing IndexPilot functionality.

This must be a real working implementation, not a static UI mockup.

---

# 2. NAVIGATION

Add a new navigation item:

**IndexPilot Algo**

Clicking it should open:

`/indexpilot-algo`

If the user is not logged in, redirect them to Login.

# 3. WORKING SIGNUP

Create a real Signup page.

Fields:

* Full Name
* Mobile Number
* Email
* Password
* Confirm Password
* Terms & Conditions checkbox

Button:

**Create Account**

Requirements:

* Backend validation
* Required-field validation
* Email validation
* Mobile validation
* Password validation
* Password confirmation
* Duplicate email detection
* Duplicate mobile detection
* User stored in database
* Password securely hashed

After successful signup:

**Account created successfully**

Then redirect to Login or automatically authenticate the user.

Do NOT use fake/local-only authentication.
